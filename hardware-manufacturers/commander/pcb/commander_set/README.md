# Commander: mainboard and keyboard side by side (view only)

`commander_set.kicad_pcb` holds both boards as they sit in the case: the mainboard (L-shape: codec column on
the left, hub strip along the top) and the keyboard to the right of the column, 1 mm below the hub strip.
Keyboard references and nets carry the prefix `KB_`, so nothing is connected between the two boards.

**For looking at and for fit checks only - do not send this file to a fabricator.** The mainboard has 6 copper
layers, the keyboard 2; each is made from its own project and Gerber package:

| Board | Project | Gerbers |
|---|---|---|
| Mainboard | `../commander_mainboard/` | `../../fabrication/gerber/commander_mainboard_*` |
| Keyboard | `../commander_keyboard/` | `../../fabrication/gerber/commander_keyboard_*` |

Both packages can go into **one order** at JLCPCB / PCBWay as two designs. Made as one panel, the keyboard
would need 6 layers as well, at several times the cost.

Generated by `../commander_mainboard/tools/make_set_view.py` (also the last step of
`build.py --variant keyboard`). Do not edit it: changes are lost at the next build.
