# Commander: mainboard, hub board and keyboard together (view only)

`commander_set.kicad_pcb` holds the three boards as they sit in the case: the mainboard (the codec column, with the
M.2 socket J41 on a small tab), the hub board (the nine bays and both USB hubs, its card edge in J41) along the top,
and the keyboard to the right of the column, 1 mm below the hub board. Hub references and nets carry the prefix
`HUB_`, keyboard ones `KB_`, so nothing is connected between the boards. The hub's card tongue lies over the
mainboard's tab (in the case it rests 0.3 mm above it), so the outlines overlap there and KiCad's 3D viewer cannot
build one board outline from this file.

**For looking at and for fit checks only - do not send this file to a fabricator.** Each board is made from its own
project and Gerber package:

| Board | Project | Copper layers | Thickness | Gerbers |
|---|---|---|---|---|
| Mainboard | `../commander_mainboard/` | 6 | 1.2 mm | `../../fabrication/gerber/commander_mainboard_*` |
| Hub board | `../commander_hub/` | 6 | 0.8 mm (M.2 card) | `../../fabrication/gerber/commander_hub_*` |
| Keyboard | `../commander_keyboard/` | 2 | 1.6 mm | `../../fabrication/gerber/commander_keyboard_*` |

The three thicknesses rule out one shared panel: the hub has to be 0.8 mm to fit the M.2 socket. All three
packages go into **one order** at JLCPCB / PCBWay as three designs.

Generated by `../commander_mainboard/tools/make_set_view.py` (also the last step of `build.py` for the mainboard,
the hub board and the keyboard). Do not edit it: changes are lost at the next build.
